Customer Complaint Management System

This project combines a Node.js/Express backend, a MongoDB data layer, and a React frontend for handling customer complaints end-to-end. Users can submit complaints, upload supporting files, track status, and receive notifications, while admins and handlers manage assignments, updates, and resolution work.

Frontend

  • Role-based user, admin, and handler screens
  • Complaint creation with optional attachments
  • Comment thread with file uploads
  • Dashboard views and complaint detail pages

Backend

  • JWT auth with role enforcement
  • Complaint lifecycle and status transitions
  • Cloudinary attachment storage
  • Notifications, audit logs, and email alerts

Key flows

  • User submits complaint and optional evidence files
  • Admin assigns complaint to a handler
  • Handler updates status and resolves complaint
  • User closes resolved complaint after confirmation
